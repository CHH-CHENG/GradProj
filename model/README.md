# model 模块（模型训练与评估）

基于特征样本训练森林蓄积量估测模型，并输出精度评估与模型解释结果。

> ✅ **已实现**：`rf.py` 已完成三模型矩阵 + 空间分块交叉验证。

## 脚本说明

### rf.py（随机森林建模）
- 功能：
  - 随机森林回归训练
  - **三模型矩阵**：①混交模型（混交样本）、②纯林模型（纯林样本）、③全局模型（全样本，按纯/混分别评估）
  - **空间分块交叉验证**：KMeans 按坐标聚成 5 个空间块 + GroupKFold 5 折（避免空间自相关虚高精度）
  - 精度评估（R² / RMSE / RMSE% / MAE）+ 特征重要性
  - SHAP 解释（可选，后续）
- **输入**：`data/feature/samples_sampled.csv`（17 特征 + GSV 标签）
- **输出**：`data/result/`（`metrics_summary.csv`、`importance_*.csv`、`rf_*.joblib`）
- **要求**：固定随机种子（42）、可复现
