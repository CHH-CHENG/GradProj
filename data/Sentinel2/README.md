存放**西班牙 IFN4 三省**（León / Burgos / Lugo）的 Sentinel-2 遥感数据及各级处理产物。


> ✅ **下载与解压均已完成**（25 个 zip / 21.26 GB，2026-09-18）

## 采集参数（`python -m downloader.spain`）

- 来源：Copernicus Data Space（CDSE），L2A 地表反射率
- 策略：**全省矩形范围查询 → 按 tile 去重（每 tile 取云量最少一期）→ 断点续传下载**
- 云量阈值：<30%（西班牙夏季晴天多，实际多为 0%）
- 时间窗：与 IFN4 各省调查年匹配（León 2019 / Burgos 2018 / Lugo 用 2016 替代 2009）

## 数据类型与内部格式

### zip/Spain_IFN4/<省>/ — 原始压缩包
- 类型：遥感影像压缩包；格式：ZIP；命名：`<产品ID(UUID)>.zip`；内部为 SAFE 产品目录

### SAFE/Spain_IFN4/ — SAFE 产品目录（✅ 已解压 25 个）
- 格式：SAFE（Sentinel-2 标准），命名 `S2A/S2B_MSIL2A_<日期>_N<...>_R<...>_T<编号>_<...>.SAFE`
- 内部格式：
  - `MTD_MSIL2A.xml`：产品元数据
  - `GRANULE/<tile>/IMG_DATA/`：波段（JP2），L2A 按分辨率分目录 `R10m/`（B02 B03 B04 B08）、`R20m/`（B05 B06 B07 B8A B11 B12 等）、`R60m/`，另含 `SCL/AOT/WVP`
  - `GRANULE/<tile>/QI_DATA/`：质量标识图层

### roi/ — ROI 裁剪影像（⏳ 待生成）
- 格式：GeoTIFF，多波段（B02~B12，10m），按研究区对齐后输出

### indices/ — 植被指数（⏳ 待生成）

## 输入来源 / 输出去向
- **输入来源**：`python -m downloader.spain` 从 CDSE 自动采集（全省矩形查询 + 每 tile 取云量最少一期）
- **输出去向**：解压 SAFE → `roi/` 裁剪 → `feature/` 按样地提取特征（与 IFN4 样地蓄积量标签匹配）
